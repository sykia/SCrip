# SCrip 1.6.1

Исправление загрузки обновлений для ПК.

- Исправлен отказ «Сервер указал некорректный размер обновления» при неизвестной длине HTTP-ответа.
- Пакет запрашивается без транспортного сжатия. Фактический размер и SHA-256 обязательно проверяются перед установкой.
- Исправлен сброс прогресса при повторной загрузке; ошибка записи блокирует готовность файла к установке.

Сборки: Windows x64, Debian 13 amd64 и Arch Linux x86-64. Android не пересобирался и остаётся на версии 1.6.0.

Исходники приложения и контрольные суммы приложены к выпуску. Материалы зависимостей восстанавливаются из `compliance-update.tar.gz` поверх материалов 1.4.0 по описателю `licensing/releases/1.6.1/release.json`.
