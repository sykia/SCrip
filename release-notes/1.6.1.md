# SCrip 1.6.1

Desktop update download fix.

- Fixed the “Server reported an invalid update size” failure when the HTTP response length is unknown.
- Request packages without transport compression. Actual size and SHA-256 are always verified before installation.
- Fixed progress reset on retry; write failures prevent files from becoming ready to install.

Builds: Windows x64, Debian 13 amd64 and Arch Linux x86-64. Android was not rebuilt and remains at 1.6.0.

Application sources and checksums accompany the release. Restore dependency materials by applying `compliance-update.tar.gz` over the 1.4.0 materials according to `licensing/releases/1.6.1/release.json`.
