# SCrip 1.4.2

Единый выпуск для Windows x64, Android, Debian 13 amd64 и Arch Linux x86-64. Включает последние исправления Android-плеера и Plugin API v2.

- Windows: установщик для текущего пользователя, без цифровой подписи издателя.
- Android 9+: универсальный Release APK для ARM64, ARMv7 и x86-64. Сохранена прежняя подпись; устанавливайте поверх существующего приложения.
- Linux: установочные пакеты DEB и Arch, без подписи пакетов.

Контрольные суммы всех файлов — в `SHA256SUMS`. Исходники приложения — в `SCrip-1.4.2-source.tar.gz`.

[Манифесты состава и соответствующие исходники](https://github.com/sykia/SCrip/tree/v1.4.2/licensing/releases/1.4.2). Неизменённые исходники зависимостей доступны в [материалах 1.4.0](https://github.com/sykia/SCrip/releases/download/v1.4.0/compliance.tar.gz); SHA-256 базового архива закреплён в `release.json`.
