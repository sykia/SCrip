# SCrip 1.4.2

A unified release for Windows x64, Android, Debian 13 amd64 and Arch Linux x86-64. Includes the latest Android player fixes and Plugin API v2.

- Windows: per-user installer without a publisher digital signature.
- Android 9+: universal Release APK for ARM64, ARMv7 and x86-64. The previous signing key is retained; install over the existing app.
- Linux: DEB and Arch packages without package signatures.

Checksums for all files are in `SHA256SUMS`. Application sources are in `SCrip-1.4.2-source.tar.gz`.

[Inventory manifests and corresponding sources](https://github.com/sykia/SCrip/tree/v1.4.2/licensing/releases/1.4.2). Unchanged dependency sources are available in the [1.4.0 materials](https://github.com/sykia/SCrip/releases/download/v1.4.0/compliance.tar.gz); the base archive's SHA-256 is pinned in `release.json`.
