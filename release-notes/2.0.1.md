# Sange 2.0.1 — Hello, Apple!

Initial macOS release for Apple Silicon and Intel; requires macOS 14.4 or newer.

- Standalone DMG packages with an Applications shortcut.
- macOS Keychain credential storage, Now Playing transport controls and Command-Q.
- Architecture-specific update downloads with SHA-256 verification.
- Local diagnostic logs and filtered report export for playback failures and stalls.
- Faster log filtering on systems without regular-expression JIT.

Both native architectures pass the eight automated test groups, isolated Keychain
checks, bundle dependency/signature validation, actual DMG inventory/source audits
and standalone Cocoa startup. Linux regression checks also pass. The synthetic
macOS offscreen touchscreen-flick case is skipped. Interactive sign-in, audible
hardware playback, sleep/wake and trackpad behavior have not been verified.

Packages use ad-hoc signatures and are not notarized by Apple. macOS may block
initial launch. Do not disable Gatekeeper globally. Complete application and
dependency sources, build recipes, license notices and per-file manifests are
provided beside the packages. Windows, Linux and Android remain at 2.0.0.
