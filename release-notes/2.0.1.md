# Sange 2.0.1 — preparation

This version is being prepared; this file does not announce a published release.

- Local diagnostic logs and a report-copying panel help investigate playback failures and main-loop stalls. Reports are filtered and are not uploaded automatically. See [diagnostics](../docs/diagnostics.md).
- Initial macOS port: standalone application bundle, Keychain credential storage, Now Playing transport controls, native Quit shortcut and separate Apple Silicon/Intel CI packages.

macOS test packages target macOS 14.4 or newer with Qt 6.12.0. They use ad-hoc signatures. Developer ID signing, notarization, a complete inventory and corresponding source/notice materials for bundled Qt and codec libraries, and interactive Mac validation are required before public release. See [macOS validation](../docs/macos.md). Existing 2.0.0 download links remain the published release until this validation is complete.
