# SCrip 1.4.1 — Android fixes

Fixed Android background playback. Listen while using other apps or with the screen locked: the playback service stays in the foreground during track transitions, and media controls remain available.

- Fixed background player shutdown during track changes and buffering.
- Headphone output and device switching on connection work correctly.
- The next track is buffered in memory ahead of time to reduce transition delays.
- System controls provide pause, resume, previous/next and a separate **Stop** action.
- Fixed handing downloaded APKs to the system installer.
- Completely removed experimental offline saving, music downloads and the offline library. This feature was the reason the 1.4.0 APK was removed from the previous release. Music streams over the network through SoundCloud.

The author tested the corrected build on a real phone: background playback and headphones work. Application tests and Android 15 service checks also passed, including background buffering beyond 30 seconds, pause, resume and stop.

This release contains only a universal **Android APK** for Android 9+, supporting ARM64, ARMv7 and x86-64. Desktop packages remain in [release 1.4.0](https://github.com/sykia/SCrip/releases/tag/v1.4.0).

The public APK is signed with the permanent release key. Test builds shared in chat use a different signature and cannot be upgraded in place. Removing a test build loses local settings and requires signing in again.
