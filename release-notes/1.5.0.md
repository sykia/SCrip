# SCrip 1.5.0

Выпуск для Windows x64, Android 9+, Debian 13 amd64 и Arch Linux x86-64.

- Защищённое хранение сессии SoundCloud, исправления авторизации и переключения аккаунтов.
- Восстановление очереди и позиции, улучшения плеера и системного управления Android.
- Оптимизированные списки, расширенный API плагинов и исправления обновления приложения.
- Windows: установщик без подписи издателя; Linux: пакеты без подписи; Android: универсальный APK для ARM64, ARMv7 и x86-64, подписанный прежним ключом.

Контрольные суммы — в `SHA256SUMS`; исходники и сведения о лицензиях прилагаются к выпуску.

[Манифесты состава и исходники](https://github.com/sykia/SCrip/tree/v1.5.0/licensing/releases/1.5.0). Исходники неизменённых зависимостей доступны в [материалах 1.4.0](https://github.com/sykia/SCrip/releases/download/v1.4.0/compliance.tar.gz); их контрольная сумма закреплена в описателе выпуска. Windows собран и проверен на [Windows runner](https://github.com/sykia/SCrip/actions/runs/42652129488).
