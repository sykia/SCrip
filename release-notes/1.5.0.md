# SCrip 1.5.0

Release for Windows x64, Android 9+, Debian 13 amd64 and Arch Linux x86-64.

- Secure SoundCloud session storage, authentication and account-switching fixes.
- Queue and position restoration, player and Android system media control improvements.
- Optimized lists, expanded plugin API and application update fixes.
- Windows: installer without a publisher signature; Linux: unsigned packages; Android: universal APK for ARM64, ARMv7 and x86-64, signed with the previous key.

Checksums are in `SHA256SUMS`; sources and licensing information accompany the release.

[Inventory manifests and sources](https://github.com/sykia/SCrip/tree/v1.5.0/licensing/releases/1.5.0). Unchanged dependency sources are available in the [1.4.0 materials](https://github.com/sykia/SCrip/releases/download/v1.4.0/compliance.tar.gz); their checksum is pinned in the release descriptor. Windows was built and checked on a [Windows runner](https://github.com/sykia/SCrip/actions/runs/42652129488).
