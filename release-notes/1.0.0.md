# SCrip 1.0.0

SoundCloud Desktop began as an Electron shell. In SCrip 1.0.0, the player and library have been rewritten in C++ and Qt Quick and use the SoundCloud API.

![SCrip Home](https://raw.githubusercontent.com/sykia/SCrip/v1.0.0/docs/screenshots/home.png)

- **Home:** personal mixes, artist stations and new releases.
- **Queue:** drag tracks into order and choose **Play next**.
- **System tray:** pause, skip tracks, like and reopen the window. Choose **Quit** to exit.
- **Settings:** custom themes, artwork shapes and plugins.

### Download

**Windows 10/11 x64:** run the EXE installer. **Debian 13 x86-64:** install the DEB package. **Arch Linux x86-64:** install the `.pkg.tar.zst` package. On first launch, sign in through the official SoundCloud page.
