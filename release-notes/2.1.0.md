# Sange 2.1.0

- Choose English or Russian in settings on desktop and Android; the choice persists between launches.
- Resume playback after temporary network failures, retry broken streams, and keep the current listening position.
- Improve desktop media-session integration and playback state synchronization.
- Refine track search, engagement controls, profile navigation, responsive layouts and interface motion.
- Correct lyrics identity, duration matching, custom-text removal and malformed synchronized lyrics.
- Fix wave recommendation ordering after queue pruning and exclude preview-only tracks from automatic selection.
- Harden stream-cache eviction, HTTP range handling and live HLS playlist refreshes.
- Keep stale resource responses from replacing the page most recently requested.

## Updating

Install over the existing installation to preserve settings, sign-in and plugins.
Android retains `org.scrip.app`, the release signing certificate and an increased
version code (20100). Windows and Linux retain their existing installation and
package identities.

The application checks GitHub for updates on startup. Download and installation
require user action; package size and SHA-256 are verified before installation.
macOS opens the verified disk image for replacement in Applications. Windows, Linux and Android 2.0.0 and older builds still allow only the former
`sykia/SCrip` download path. Their first upgrade to 2.1.0 requires a manual
download and installation over the existing app. macOS 2.0.1 and the 2.1.0
updater use the current `sykia/sange` path.

macOS requires 14.4 or newer. The disk images use ad-hoc signing and are not
Apple-notarized. Live SoundCloud sessions and physical-device playback are not
covered by the automated release checks.
