# Sange 2.2.0

A smoother touch interface, a redesigned desktop mini-player and more resilient playback.

## Added

- Network-access diagnostics and playback proxy controls in settings.
- A redesigned desktop mini-player with native window effects.
- Swipe dismissal from Android sheet headers.

## Improved

- Android sheets follow your finger, reverse direction immediately and settle according to release speed.
- Album and playlist previews animate as one surface.
- The Home wave fades behind the player and avoids shader work while hidden.
- More consistent emoji alignment in track metadata, the player and menus.
- Linux and Windows executables are now `sange` and `sange.exe`; existing installation and storage identities are preserved.

## Fixed

- UI hangs during network recovery and decoder teardown. The media proxy now runs on a dedicated thread, closes stalled requests before replacing playback and cancels preloading during recovery.
- Artwork and waveform handling, plus authentication-service rate-limit behavior.
- Linux desktop application identification.

## Updating

Install over your current application to retain settings and music data. Android keeps `org.scrip.app`, the release signing identity and an increased version code (20200). Windows and Linux retain their existing package and installation identities.

Windows, Linux and Android 2.0.0 and older require a one-time manual download because their updater uses the former repository path. macOS requires 14.4 or later; disk images are not Apple-notarized.

Packages target Windows x64, Debian 13 x64, Arch Linux x64, Android (ARM64, ARMv7 and x86-64), and macOS (Apple Silicon and Intel).
