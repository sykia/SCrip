# SCrip 1.6.0

Extensive playback, appearance and stability improvements for SCrip on desktop and Android.

- **Rapid track switching.** Fixed track transitions and stale request handling. The stream cache prioritizes current playback, and next-track preloading does not interfere with starting the selected track.
- **Light and dark themes.** Updated text, control and plugin panel colors. Added smooth appearance transitions that respect animation settings.
- **Player and queue.** Fixed seeking, **Play next** and player state synchronization.
- **Android.** Updated app icons and improved the background service. Included an FFmpeg HLS seeking fix.

The APK is signed with SCrip's permanent release key. File checksums are in `SHA256SUMS`. Previous Windows releases were distributed without Authenticode; no publisher certificate is available for this signature.

Builds: Windows x64, Android 9+ (ARM64, ARMv7, x86-64), Debian 13 amd64 and Arch Linux x86-64.

Validation covered five CTest suites, 22 Python tests, HLS playback after seeking, the Android service lifecycle and APK installation/launch on an emulator. Windows EXE startup through Wine and Windows installer integration tests in GitHub Actions were checked. Real-device testing and a separate manual Windows check remain outside this validation.

Application sources: `SCrip-1.6.0-source.tar.gz`. `compliance-update.tar.gz` contains new manifests, notices and sources for modified components. Apply it over the [1.4.0 dependency materials](https://github.com/sykia/SCrip/releases/download/v1.4.0/compliance.tar.gz); both archive SHA-256 hashes are pinned in the [release descriptor](https://github.com/sykia/SCrip/blob/v1.6.0/licensing/releases/1.6.0/release.json). Restore and audit materials using `prepare_release_materials.py` and `audit_release.py` from the source tree.
