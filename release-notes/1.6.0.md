# SCrip 1.6.0

Проведена большая работа над воспроизведением, оформлением и стабильностью SCrip на компьютере и Android.

- **Быстрое переключение песен.** Исправлена обработка смены треков и устаревших запросов. Кэш потоков отдаёт приоритет текущему воспроизведению, а предварительная загрузка следующей песни не мешает запуску выбранной.
- **Светлая и тёмная темы.** Обновлены цвета текста, элементов управления и панелей плагинов. Добавлено плавное переключение оформления с учётом настройки анимаций.
- **Плеер и очередь.** Исправлены перемотка, действие «Играть следующим» и синхронизация состояния плеера.
- **Android.** Обновлены значки приложения, улучшена работа фоновой службы. Включено исправление перемотки HLS в FFmpeg.

APK подписан постоянным релизным ключом SCrip. Контрольные суммы файлов приведены в `SHA256SUMS`. Windows в предыдущих выпусках распространялся без Authenticode; сертификат издателя для этой подписи отсутствует.


Сборки: Windows x64, Android 9+ (ARM64, ARMv7, x86-64), Debian 13 amd64 и Arch Linux x86-64.

Проверены пять наборов CTest, 22 Python-теста, воспроизведение HLS после перемотки, жизненный цикл Android-службы и установка с запуском APK на эмуляторе. Проверены запуск Windows EXE через Wine и интеграционные тесты Windows-установщика в GitHub Actions. Реальное устройство и отдельная ручная проверка Windows остаются за пределами этих проверок.

Исходники приложения — `SCrip-1.6.0-source.tar.gz`. `compliance-update.tar.gz` содержит новые манифесты, уведомления и исходники изменённых компонентов. Он применяется поверх [материалов зависимостей 1.4.0](https://github.com/sykia/SCrip/releases/download/v1.4.0/compliance.tar.gz); SHA-256 обоих архивов закреплены в [описателе выпуска](https://github.com/sykia/SCrip/blob/v1.6.0/licensing/releases/1.6.0/release.json). Восстановление и аудит выполняются скриптами `prepare_release_materials.py` и `audit_release.py` из исходников.
