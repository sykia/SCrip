# Sange 2.0.0

SCrip becomes Sange. Desktop and Android show the new name and version.

## Upgrade compatibility

Install over SCrip without uninstalling it. Linux keeps the `scrip` package, executable and desktop-file IDs. Windows keeps its install location, executable and uninstall registry key. Android keeps `org.scrip.app` and must use the existing release signing certificate. Settings, Secret Service records, DPAPI records and Android Keystore aliases retain their existing identities. No token export or credential migration is required.

Existing `scrip://` links and QML module paths remain supported. Plugin files and settings are preserved; plugins declaring a host limit below 2.0.0 require an updated manifest from their author. Bundled examples now accept host versions below 3.0.0. A session that has expired or been revoked by SoundCloud still requires sign-in.

## Sign-in recovery

When SoundCloud denies authorization or the token exchange fails, the browser callback page offers **Retry sign-in**. It redirects the current tab to SoundCloud with fresh PKCE and state. The one-use retry capability expires with the ten-minute login timeout, and cancellation closes the listener. Invalid state never starts a token exchange or exposes a retry capability.

## Release validation

Publication requires passing Linux tests and license/secret checks, validated platform packages, matching Android signing identity and the corresponding source and compliance materials. Windows and Android runtime verification must be recorded separately from Linux results. Historical release records remain unchanged.
