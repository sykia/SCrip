# Плагины SCrip

Доступны API v1 и декларативный [API v2](plugin-api-v2-reference.md) с разрешениями, обновлением и дополнениями плеера. Ниже описан совместимый формат v1. [Архитектурное решение v2](plugin-api-v2.md) сохранено отдельно.

Войдите в приложение, откройте **Настройки → Плагины → Установить из файла…** и выберите [Студию](../examples/plugins/studio.json). Нажмите **Включить**. На главной появится панель «Моя музыка». В настройках плагина можно отдельно отключить портреты исполнителей и сохранить кнопки и цвет темы.

## Устройство файла

Плагин — локальный JSON в UTF-8. Поля верхнего уровня обязательны.

| Поле | Значение |
| --- | --- |
| api | Число 1 |
| id | Уникальный идентификатор длиной до 48 знаков. Первый знак — строчная латинская буква, далее разрешены также цифры, точка и дефис |
| name | Название до 48 знаков |
| groups | От одной до шести групп. Каждая получает собственный переключатель |

В каждой группе обязательно поле `label` длиной до 48 знаков. Остальные поля необязательны.

| Поле | Эффект |
| --- | --- |
| accent | Цвет акцента приложения в формате #RRGGBB |
| coverRadius | Радиус обложек от 0 до 24 пикселей, целое число |
| covers | artwork — обычная обложка, artist — аватар автора с возвратом к обложке при отсутствии аватара |
| page | home или profile. Создаёт панель с заголовком из label на указанной странице |
| text | Подпись панели до 180 знаков. Требует page |
| buttons | До четырёх кнопок панели. Требует page |

У кнопки два обязательных поля — видимое название `label` до 32 знаков и команда `action`. Поддерживаются переходы в любимые треки (likes), историю (history), ленту (feed), плейлисты (playlists), профиль (profile) и поиск (search).

## Приоритет и хранение

SCrip применяет включённые группы в порядке установки плагинов и порядке групп в файле. При совпадении свойства действует последнее значение. Отключение сразу возвращает предыдущее оформление. Список, настройки и копии описаний сохраняются в plugins-v1.json в каталоге данных приложения. Исходный файл после установки можно переместить. Для замены используйте «Обновить из файла»: при полном совпадении groups переключатели сохранятся; при изменении групп предпросмотр предупредит об их сбросе. При первом запуске нового менеджера записи импортируются в plugins-v2.json с сохранением включения и флагов; исходный v1-файл остаётся нетронутым.

## Граница доступа

SCrip сам рисует элементы и обрабатывает нажатия. Плагину доступны только перечисленные поля и команды. Загрузчик отвергает неизвестные поля, произвольные URL и команды в полях действий. Вывод текста ограничен печатными символами без угловых скобок. Интерпретатора скриптов нет. Плагин не получает объекты SoundCloud, содержимое профиля, токены, сетевой клиент или файловый API. Для обложек приложение использует уже полученные адреса SoundCloud.

Установка и включение выполняются отдельно. Пределы установки — 32 КиБ на файл и 24 плагина. Эти ограничения относятся к расширениям внутри SCrip. Они не защищают данные от сторонних программ, запущенных пользователем.
