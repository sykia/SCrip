<h2 align="center">Your SoundCloud music, in a dedicated player</h2>

<p align="center">Windows · Linux · Android</p>

<p align="center"><a href="https://github.com/sykia/sange/releases/latest">Download Sange</a> · <a href="Installation">Installation</a> · <a href="Troubleshooting">Get help</a></p>

Sange is an independent SoundCloud player built with C++20 and Qt Quick. Discover music, manage playlists and keep listening with system media controls. It uses the official SoundCloud API and is not an official SoundCloud product.

## Start here

1. [Install the package](Installation) for your platform.
2. [Sign in to SoundCloud](SoundCloud-Authentication) in your browser.
3. Explore Home, search for music, or open your likes and playlists.

## Upgrading from SCrip

Version 2.0.0 renamed SCrip to Sange. Install over the existing application without uninstalling or clearing data. Version 2.2.0 uses `sange` / `sange.exe` on Linux and Windows. The Linux package name, installation directories, stored settings and Android package identity remain compatible. Android updates require the same signing certificate. See [Installation](Installation#upgrading).
