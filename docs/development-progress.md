# Release validation

Current target: **Sange 2.0.0**. See [release notes](../release-notes/2.0.0.md) for user-visible changes and upgrade compatibility.

## Required checks

- Configure and build: `cmake --preset debug`, `cmake --build --preset debug`.
- Run CTest with a session D-Bus, an unlocked isolated Secret Service, virtual audio output and the HLS fixture generated by `tests/run-hls-seek.sh --generate-only`.
- Run `bash tests/run-secretstore-linux.sh` for real Secret Service persistence and unavailable-service behavior.
- Run `node --test tests/worker.test.mjs` and `python -m unittest discover -s tests -p 'test_*.py'`.
- Run `python scripts/check_licenses.py --repo .`, `python scripts/check_secrets.py --mode tracked` and `git diff --check`.
- Verify Windows installer rollback, interrupted-update recovery and upgrades on Windows.
- Verify Android APK package/version, all supported ABIs, signing certificate continuity and lifecycle behavior.
- Audit final packages against the release compliance materials before publication.

Build and test output belongs in `build/`. Never commit signing keys, passwords or user sessions. A successful build does not establish platform runtime or upgrade correctness.
